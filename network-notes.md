# Как работает интернет: от Enter до страницы

- Мы вводим сайт в посиковую строку, браузер сначала ищет IP-адрес в кеше (браузер, ОС), если он его не находит там в работу вступает рекурсивный резолвер, он ищет его в своем кеше, и если есть запись с актуальным DNS TTL возвращает IP. Если там не найден адрес, обращение идет в корневой сервер, который направляет запросы к соответствующим серверам верхнего уровня (TLD серверу) и идет напрвление в DNS и находит там IP. Весь этот процесс идет по UDP на порту 53 — быстро, без установки соединения, с возможностью потери пакетов. После этого мы устанавливаем TCP соединение через 3 рукопожатия (SYN->SYN ACK->ACK), поверх которого идет TLS-хендшейк которая шифрует наши данные. После этого отправляется HTTP-запрос методом GET с заголовками (Host, User-Agent) поверх TCP. Сервер возвращает ответ с HTML, CSS, JS, после чего браузер выполняет JS и рендерит страницу. 

Ключевые определения:
- **Рекурсивный резолвер** - это сервер который выдает провайдер когда мы устанавливаем интернет либо google сам его дает.
- **TTL** — это время жизни записи в кеше.
- **TLD-сервер** — сервер верхнего уровня

## TCP vs UDP

- **UDP** — быстрый, без соединения, без гарантий доставки. Используется для DNS, видеозвонков, стримов, игр.
- **TCP** — надёжный, с соединением, с гарантией доставки и порядка. Используется для HTTP, HTTPS, почты, SSH.
