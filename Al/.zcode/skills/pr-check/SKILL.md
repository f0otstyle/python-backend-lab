# Проверка PR (фиксированный пайплайн)

При активации выполняй РОВНО эти шаги по порядку. Не пропускай, не объединяй и не меняй порядок.

## Шаг 1: Область изменений
Выполни `git diff main...HEAD --name-only` и `git ls-files --others --exclude-standard`, чтобы получить полный список изменённых и незафиксированных файлов. Верни список.

## Шаг 2: Линт (параллельно, по файлам)
Для КАЖДОГО изменённого файла запусти субагента с инструкцией:
- Запусти линтер проекта только для этого файла.
- Верни ТОЛЬКО ошибки и предупреждения. Без вступлений.
Собери результаты в `lint_report.md`.

## Шаг 3: Тесты (параллельно, по изменённым модулям)
Для КАЖДОГО изменённого модуля запусти субагента:
- Запусти релевантные тесты для этого модуля.
- Верни ТОЛЬКО имена упавших тестов и строки ошибок.
Собери результаты в `test_report.md`.

## Шаг 4: Ревью (один субагент)
Запусти ОДНОГО субагента с диффом + `lint_report.md` + `test_report.md`.
Инструкция: «Проверь дифф. Сопоставь с находками линта и тестов. Верни приоритизированный список проблем: критичные, серьёзные, мелкие. Кратко.»

## Шаг 5: Сборка
Объедини все отчёты в `review_summary.md` с разделами:
1. Изменённые файлы
2. Ошибки линта
3. Упавшие тесты
4. Замечания ревью (по приоритету)

Выведи сводку пользователю. Не добавляй комментарии от себя.
