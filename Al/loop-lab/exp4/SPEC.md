# SPEC: stats.py — mean и max_diff

## Цель

Создать модуль `stats.py` с двумя функциями для базовой статистики числовой последовательности:

- `mean(numbers)` — среднее арифметическое;
- `max_diff(numbers)` — максимальная абсолютная разность соседних элементов.

## Шаги

1. Создать файл `loop-lab/exp4/stats.py` с докстрингами на русском языке.
2. Реализовать `mean(numbers)`: сумма элементов, делённая на их количество.
3. Реализовать `max_diff(numbers)`: максимум из `abs(numbers[i+1] - numbers[i])` по всем соседним парам.
4. Добавить обработку краевых случаев: пустой вход для `mean` и вход короче двух элементов для `max_diff` — `ValueError`.
5. Проверить работу функций на примере при запуске модуля как скрипта (`python stats.py`).

## Критерии готовности (DoD)

- [ ] Файл `loop-lab/exp4/stats.py` существует и импортируется без ошибок.
- [ ] Обе функции имеют докстринги на русском (что делает, аргумент, возвращаемое значение).
- [ ] `mean([1, 2, 3, 4]) == 2.5`; `max_diff([2, 10, 3]) == 8`.
- [ ] Пустой список: `mean([])` и `max_diff([5])` (меньше двух элементов) бросают `ValueError` с понятным сообщением.
- [ ] Запуск `python stats.py` выводит демонстрационные результаты без ошибок.

## Границы

- Только стандартная библиотека Python, без внешних зависимостей.
- Вход — список/кортеж чисел (int/float); строки и `None` не поддерживаются.
- Нет CLI-аргументов, чтения файлов и работы с numpy/statistics — самодостаточный учебный модуль.
- Нет покрытий pytest в рамках этой задачи: проверка — демонстрационный запуск `python stats.py`.
