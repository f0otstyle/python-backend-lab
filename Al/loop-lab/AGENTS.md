# AGENTS.md — loop-lab

> Инструкция для ИИ-агента. Читай перед началом работы.
> Файл описывает правила лабы, а не конкретные эксперименты: новый
> эксперимент вписывается в них без правки этого файла.
> Обновлено: 2026-11-10

## Назначение

Учебная лаборатория asyncio: серия независимых экспериментов над поведением
event loop. Эксперимент — самодостаточная папка со своим сервером и клиентами.
Цель — наблюдать и измерять, а не «сделать продукт».

## Паттерн запуска

```bash
# из корня loop-lab:
pip install -r requirements.txt

# из папки эксперимента (exp1, exp2, ...):
uvicorn server:app --port 8000    # в разработке обычно добавляешь --reload
python client_1.py
```

- Один и тот же набор команд работает для любого эксперимента —
  меняется только имя папки.
- Адрес сервера переопределяется переменной окружения `LAB_URL`.

## Соглашения по структуре и коду

- Один эксперимент = одна папка `exp<N>/` — следующий свободный номер.
  Внутри: `server.py` (стенд), `client_<номер>.py` (сценарии), заметки.
- Заметки эксперимента (Прогноз → Факт → Почему разошлись) живут внутри
  его папки, а не здесь — поэтому AGENTS.md не правится при появлении
  нового эксперимента.
- Константы эксперимента вверху клиента: `DELAY`, `BLOCKING_DELAY`, `COUNT`.
- Комментарии, логи, докстринги — на русском; стиль — как в соседних файлах.

## Политика тестов

- «Готово» проверяется делом, а не словами: `python -m py_compile *.py`
  в папке эксперимента; `GET /health` → `{"status": "ok"}`; клиент печатает
  «Итог: N/M ...».
- Автотестов в лабе нет — проверка = запуск сервера и клиента.
- Не запустил — не заявляй, что работает.

## Ограничения (нарушать нельзя)

- Работай только в папке своего эксперимента; другие `exp<N>/` и корень
  лабы не трогать.
- `server.py` не редактировать без моего явного разрешения — предложения
  текстом.
- Константы экспериментов (`DELAY`, `BLOCKING_DELAY`, `COUNT`) не менять.
- Сервер не запускать, если я не попросил; зависимости не добавлять без спроса.
- Команды нет в списке — спроси, не выдумывай.
